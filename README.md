Mangomist Resort – 237.4 kW Solar PV Design

Project Overview

This project showcases a 37.4 kW rooftop solar PV system design prepared using AutoCAD and SketchUp.

Design Work

- Rooftop solar panel layout
- Single Line Diagram (SLD)
- Inverter and string layout
- Mounting structure layout
- Earthing layout
- Electrical equipment layout
- Cable routing and basic electrical drafting
- 3D rooftop modeling using SketchUp

Software Used

- AutoCAD
- SketchUp

Project Scope

The drawings demonstrate the planning and drafting of a rooftop solar PV system based on the available project inputs and measurements.

System Capacity: 237.4 kW
Project Type: Rooftop Solar PV System
